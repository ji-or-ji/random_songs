# 随机点歌系统

一个基于Python的命令行随机点歌系统，支持歌曲管理和随机播放功能。

## 功能特性

- 🎵 **随机点歌** - 从歌曲库中随机选择一首歌曲播放
- ➕ **添加歌曲** - 添加新的歌曲到歌曲库
- ✏️ **修改歌曲** - 修改现有歌曲的名称、歌手或外链URL
- 🗑️ **删除歌曲** - 从歌曲库中删除指定歌曲
- 📋 **查看歌曲** - 浏览当前歌曲库中的所有歌曲
- 💾 **数据持久化** - 使用JSON文件存储歌曲数据

## 安装和运行

### 系统要求
- Python 3.6+
- 支持的命令行终端

### 运行步骤
1. 确保所有文件在同一目录下：
   - `main_data/nain.py` (主程序)
   - `songs_list.json` (歌曲数据文件)

2. 打开命令行终端，导航到程序所在目录

3. 运行程序：
   ```bash
   python main_data/nain.py
   ```

## 使用指南

### 主菜单
程序启动后显示主菜单：
```
=== 随机点歌系统 ===
1. 随机点歌
2. 查看所有歌曲
3. 搜索歌曲
4. 退出
5. 歌曲管理
```

### 1. 随机点歌
选择选项1，系统会从歌曲库中随机选择一首歌曲并显示信息：
```
🎵 正在播放随机歌曲...
歌曲名称: [歌曲名]
歌手: [歌手名]
外链: [URL链接]
```

### 2. 查看所有歌曲
选择选项2，显示歌曲库中所有歌曲的列表（按ID排序）。

### 3. 搜索歌曲
选择选项3，输入关键词搜索歌曲名称或歌手。

### 5. 歌曲管理（新增功能）
选择选项5进入歌曲管理子菜单：
```
=== 歌曲管理 ===
1. 添加歌曲
2. 修改歌曲
3. 删除歌曲
4. 返回主菜单
```

#### 添加歌曲
选择1，按照提示输入：
- 歌曲名称
- 歌手名称  
- 外链URL

系统会自动为新歌曲生成唯一ID并保存。

#### 修改歌曲
选择2，首先显示所有歌曲列表，然后：
1. 输入要修改的歌曲ID
2. 选择要修改的字段（名称、歌手、外链）
3. 输入新的内容

#### 删除歌曲
选择3，首先显示所有歌曲列表，然后：
1. 输入要删除的歌曲ID
2. 确认删除操作（输入Y确认）

### 数据文件格式
歌曲数据存储在`songs_list.json`中，格式如下：
```json
{
  "songs": [
    {
      "id": 1,
      "name": "歌曲名称",
      "singer": "歌手名称", 
      "url": "https://外链地址"
    }
  ]
}
```

## 注意事项

1. **数据备份**：在进行大量修改前建议备份`songs_list.json`文件
2. **URL格式**：添加歌曲时请确保外链URL格式正确
3. **ID系统**：歌曲ID由系统自动生成，请不要手动修改
4. **文件权限**：确保程序有读写`songs_list.json`文件的权限

## 故障排除

### 常见问题
1. **程序无法启动**：检查Python是否正确安装
2. **文件读写错误**：检查文件权限和路径
3. **JSON格式错误**：不要手动编辑JSON文件，使用程序管理

### 获取帮助
如遇到问题，请检查：
- Python版本是否符合要求
- 所有文件是否在正确目录
- 文件权限是否足够

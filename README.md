# 🎵 随机点歌系统

一个功能丰富的Python命令行随机点歌系统，支持完整的歌曲管理、点歌人管理、操作历史记录和统计分析功能。

## ✨ 核心功能

### 🎲 随机点歌
- 从歌曲库中智能随机选择歌曲播放
- 自动过滤无效歌曲（空歌名或空歌手）
- 显示完整的歌曲信息，包括点歌人

### 📊 统计分析
- 实时统计歌曲总数、有效/无效歌曲数量
- 点歌人排行榜统计
- 可视化数据展示

### 👥 点歌人管理
- **添加点歌人** - 创建新的点歌人账户
- **删除点歌人** - 删除点歌人及其所有歌曲
- **修改点歌人** - 重命名点歌人姓名
- **查看点歌人列表** - 浏览所有点歌人

### 🎵 歌曲管理
- **添加歌曲** - 添加新歌曲到库中
- **修改歌曲** - 编辑歌曲名称、歌手、外链URL或点歌人
- **删除歌曲** - 从库中移除指定歌曲
- **查看所有歌曲** - 浏览完整的歌曲列表

### 📜 操作历史
- 完整的操作日志记录
- 时间戳记录所有重要操作
- 支持查看历史记录

### 🔄 数据持久化
- 自动保存所有更改到JSON文件
- 支持多个文件路径查找
- 数据损坏自动恢复机制

## 🚀 快速开始

### 系统要求
- **Python 3.6+**
- 支持的命令行终端

### 安装和运行

1. **确保文件结构正确**：
   ```
   random_songs/
   ├── main_data/
   │   ├── main.py          # 主程序
   │   └── history_records.json  # 历史记录文件
   ├── songs_list.json      # 歌曲数据文件
   └── README.md           # 说明文档
   ```

2. **运行程序**：
   ```bash
   cd d:/random_songs
   python main_data/nain.py
   ```

## 🔧 技术特性

### 智能文件查找
程序支持在多个路径查找数据文件：
- 当前目录
- 父目录
- main_data子目录
- 相对路径和绝对路径

### 错误处理
- JSON文件损坏自动恢复
- 无效输入验证
- 文件权限检查
- 操作失败回滚机制

### 数据完整性
- 自动生成唯一歌曲ID
- 过滤无效歌曲数据
- 操作历史记录保障可追溯性

## ⚠️ 注意事项  

### 文件管理
1. **备份重要数据**：在进行大量修改前建议备份数据文件
2. **不要手动编辑JSON**：使用程序功能管理数据，避免格式错误
3. **文件权限**：确保程序有读写数据文件的权限

### 使用建议
1. **定期查看统计**：了解歌曲库状态和点歌人活跃度
2. **清理无效数据**：定期使用统计功能查看无效歌曲
3. **利用历史记录**：追踪所有操作便于审计

## 🐛 故障排除

### 常见问题

1. **程序无法启动**
   - 检查Python是否正确安装：`python --version`
   - 确认文件路径正确

2. **文件读写错误**
   - 检查文件权限
   - 确认文件没有被其他程序占用

3. **数据损坏**
   - 不要手动编辑JSON文件
   - 使用备份文件恢复

4. **操作失败**
   - 检查磁盘空间
   - 确认有足够的权限

### 获取帮助
如遇到问题，请检查：
- Python版本是否符合要求 (3.6+)
- 所有必要文件是否在正确目录
- 文件权限是否足够
